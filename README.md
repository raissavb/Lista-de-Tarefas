# Lista de Tarefas

Aplicação web de lista de tarefas com Python e Flask.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Remover tarefas

## Tecnologias

- Python
- Flask
- HTML
- CSS

## Como rodar

```bash

git clone https://github.com/raissavb/Lista-de-Tarefas.git

cd Lista-de-Tarefas

pip install flask

python app.py

```

Acesse `http://127.0.0.1:5000` no navegador.
